# NoSQL Database Lab 1

This lab is one of the possible choices for the 2 required database labs.

In this lab, you are being asked to create a database management system that allows for the storage and manipulation of user entered academic histories and opinions. Assuming that this is being implemented in a social media setting, this lab also requires user filtering and commenting. Your solution should be web hosted and demonstrate a variety of administrative roles.

This lab requires a conversation with Professor Enke regarding your choice of database and the implementation of your system. In addition, the system requirements for the system must be discussed and approved with Professor Enke.

Demonstrate and discuss your lab solution with Professor Enke and upon approval submit all the files you have created via BlackBoard.
