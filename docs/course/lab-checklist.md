# Capstone Lab Checklist

To help you be successful in completing your labs please be sure to have completed the following:

1. [ ] **A conversation and approval from Prof. Enke is required.**
2. [ ] **Needs Assessment(s)**
   - [ ] Focus on the problem not the symptoms.
   - [ ] Provide evolutions of your needs assessment if necessary.
   - [ ] Your needs assessment must be appropriate to both the problem and solution.
     - In other words, not every problem requires every engineering problem solving technique, but some do.
3. [ ] **Lab Self Evaluation(s) if appropriate**
   - [ ] Record your responses and actions to each peer evaluation.
4. [ ] **Functionality**
   - [ ] Does your solution work?
   - [ ] Does it meet client demands?
   - [ ] Is the user experience appropriate?
5. [ ] **Secure coding and security best practices**
6. [ ] **Appropriate user interface**
7. [ ] **Ready for deployment if appropriate**
8. [ ] **Demonstration, discussion and approval from Prof. Enke before submission**

## Capstone Lab Reminder

- 2 Labs must be selected from the database options.
- 4 Labs must be self-generated and receive approval from Prof. Enke.
- Others to be chosen from approved lab topics or specific approval from Prof. Enke.
